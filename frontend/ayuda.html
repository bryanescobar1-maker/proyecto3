Guía de uso

1. Proveedores: registra un software y configura las licencias contratadas (un número mayor que cero para poder asignarlas).

2. Empleados: entra a Asignación de licencias y registra a tus empleados.

3. Asignar: usa «Asignar licencia», selecciona el empleado y el software con cupos disponibles.

4. Liberar: en la tabla de licencias asignadas usa «Liberar».

Si aparece «No hay licencias disponibles», ve a Proveedores → Editar y establece las licencias contratadas.
