# Panel de Administración de Licencias SaaS - Cómputo en la Nube 2026

Este repositorio contiene el sistema de control de gastos, asignación de licencias y alertas automáticas integradas con servicios de AWS.

---

## Prototipos de Interfaz (Fase 1)

El diseño visual y el flujo interactivo de la plataforma han sido desarrollados siguiendo las directrices de la rúbrica de la UNICAES.

*[Haga clic aquí para abrir el Prototipo Interactivo en Figma](https://www.figma.com/design/Bq6MoPUwGJUw5NHvv8XUIX/administraci%C3%B3n-de-software-y-suscripciones-SaaS?node-id=2-4450&t=yxDmc1jReKa6R4l0-0)*

### Módulos Diseñados:
* *Panel de Control / Dashboard:* Visualización del gasto total mensual ($1,250.00), gráficos y sección de alertas críticas de vencimiento.
* *Gestión de Proveedores SaaS:* Tablas funcionales con botones para procesos CRUD (Registrar, Editar, Eliminar).
* *Asignación de Licencias:* Control de accesos y visualización de recursos vinculados a los empleados.
